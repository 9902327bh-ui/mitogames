# Biology 3D graphics audit

## Scope and comparison source

The requested `./_reference_chem/` directory is not present in this checkout. I used the live Chemistry implementation in `src/verbatim/components/Lab3D.tsx` and `src/verbatim/three/LabRoom.ts` as the comparison source. Those files are reference-only for this work and will not be edited.

The Biology renderer already matches several Chemistry foundations: ACES filmic tone mapping, exposure 1.08, PCF soft shadows, pixel ratio capped at 2, software-WebGL detection, a PMREM `RoomEnvironment`, a warm key light and cool fill, instanced particles, a target ring, camera dolly, hand cursor, and shared lab audio. The main gap is consistency and finish across Biology-specific assets and effects, not a missing 3D foundation.

## Biology models to revisit

The model upgrade pass should inspect all model builders in `src/verbatimBio/three/models/`: `safetyGear.ts`, `microscope.ts`, `glassware.ts`, `factoryModels.ts`, `anatomyModels.ts`, `specimens.ts`, `controlPanelModels.ts`, `bottlesAndTools.ts`, and `shared.ts`. The scene-specific models shown in the captures are onion specimen/microscope apparatus, the photosynthesis factory assembly, pondweed process equipment, and heart/lung circulation anatomy. Keep item IDs, benchmark positions, interaction pivots, and the experiment JSON schema stable.

Phase 2 introduced `src/three/materials.ts` and wired a quality-aware, scene-scoped material library into the Biology model builders. The implemented material upgrades cover reusable glass, independent animated liquids, veined leaf/waxy/organic materials, microscope metal, control-panel metal, onion bulb/peel geometry, and heart surface vessels/lung lobules. Model families not directly mentioned here retain their prior mesh construction and working fallbacks.

Phase 3 now marks the active source/target with a gold emissive ring/arrow and a readable world-space label, gives the hovered model a temporary material lift, adds a brief red light flash to the existing wrong-click shake, and adds an overshoot pop/sparkle burst to accepted clicks. It reuses the existing custom glove cursor and leaves raycast IDs and accepted-click conditions unchanged.

Phase 4 adds quintic/elastic/spring easings and a chained-tween helper, uses a staged anticipation/spring/settle cue for each step, lengthens camera dolly focus to 1.35 seconds, and adds restrained camera and meniscus idle motion (disabled for reduced-motion users and while the player is orbiting). Existing per-action completion delays and result mutations remain in `Bio3D.tsx`; this phase only changes their visual timing/easing.

## Behavior boundary

The visual work must preserve the safety-gear first step, guided source/target click steps, science note after every step, completion modal, and quiz entry only after lab completion. No server, quiz, experiment schema, score, accuracy, or mission-flow changes are in scope. Missing assets and reduced-quality rendering must retain the current working model/renderer fallback.
